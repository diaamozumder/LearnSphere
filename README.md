## 📌 Project Overview

LearnSphere is an AI-powered learning web application designed to provide users with an interactive and engaging digital learning experience.

The project integrates modern frontend technologies with the Google Gemini API to incorporate AI-powered functionality into the application.

The goal of LearnSphere is to make digital learning more accessible, interactive, and user-friendly through a modern web interface.

## 🚀 Installation and Setup

Follow these steps to run LearnSphere locally.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### Step 1: Clone the Repository

```bash
git clone https://github.com/diaamozumder/LearnSphere.git
```

### Step 2: Navigate to the Project Directory

```bash
cd LearnSphere
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Configure Environment Variables

Create a file named `.env.local` in the root directory.

Add your Google Gemini API key:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Replace `your_gemini_api_key` with your own API key.

**Important:** Never upload your actual API key to GitHub.

### Step 5: Run the Application

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Step 6: Build for Production

```bash
npm run build
```
